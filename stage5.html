01流形 Manifold

角度、四元数这类参数自带约束：角度按 2π 循环、四元数必须单位长度。直接当普通变量更新会破坏约束，所以要声明流形：

四元数参数块
problem.AddParameterBlock(q, 4,
    new ceres::EigenQuaternionManifold());
// 角度用 ceres::AngleManifold / Normalize 处理周期性
何时必须用

只要参数有数学约束（周期性、单位长度、正交性），更新就必须限制在流形切空间内，否则四元数不再是单位四元数。

坑

Eigen 四元数内存布局是 [x,y,z,w]，实部在最后；而构造函数接受 (w,x,y,z)。Ceres 操作裸指针，这个差异很关键。

03Bundle Adjustment

给定特征点观测与对应关系，同时优化三维点坐标和相机参数，最小化重投影误差。每个残差依赖一个 3D 点和一个 9 参数相机（3 旋转 + 3 平移 + 1 焦距 + 2 径向畸变）。

重投影误差核心
template <typename T>
bool operator()(const T* const camera, const T* const point, T* r) const {
  T p[3];
  ceres::AngleAxisRotatePoint(camera, point, p);  // camera[0,1,2] 轴角旋转
  p[0] += camera[3]; p[1] += camera[4]; p[2] += camera[5]; // 平移
  T xp = -p[0]/p[2], yp = -p[1]/p[2];             // 投影
  T r2 = xp*xp + yp*yp;
  T d = 1.0 + r2*(camera[7] + camera[8]*r2);      // 径向畸变
  r[0] = camera[6]*d*xp - T(observed_x);
  r[1] = camera[6]*d*yp - T(observed_y);
  return true;
}
// AutoDiffCostFunction<SnavelyReprojectionError, 2, 9, 3>

手推这个雅可比很痛苦，自动微分让它变得简洁——这正是 AutoDiff 在复杂模型里的价值。

04Pose Graph SLAM

SLAM = 边建图边定位。位姿图把问题抽象成：节点是机器人位姿，边是两节点间的相对变换（来自里程计或扫描匹配）。

2D

位置 + 朝向角

状态 [pᵀ, ψ]ᵀ，残差含平移差与归一化角度差，用 AngleManifold 处理角度周期性。

3D

位置 + 四元数

状态 [pᵀ, qᵀ]ᵀ，用 EigenQuaternionManifold 保证单位约束，结合 Eigen 几何模块。

残差通常还要乘测量协方差逆平方根 Σ^(-1/2)，表示对这条边有多信任。

06原理深挖：Schur 补与流形背后的数学

MATH + ANIMATION

阶段 5 的两个"黑科技"——BA 为什么用 Schur 求解器能飞快、四元数为什么要声明流形——都有清晰的数学原理。这章各给你一个动画。

① Schur 补：先把三维点"消元"掉

BA 要同时优化相机参数和三维点，正规方程 H·Δx = −b 巨大。但 H 有特殊的分块稀疏结构：相机之间、点与点之间几乎无直接关联，只有"某相机看到了某点"处才有非零块：

H = [ B   E ;   Eᵀ   C ]    B=相机块, C=点块(块对角,极易求逆), E=观测耦合

因为 C 是块对角的，C⁻¹ 非常好算。用 Schur 补把点消掉，问题从"相机+点"缩小到只解相机：

Schur 补 S = B − E·C⁻¹·Eᵀ  →  先解 S·Δ相机 = −b′  →  再回代求 Δ点

点的数量通常远多于相机，消元后矩阵从几十万维骤降到几千维——这就是 SCHUR 求解器快的原因。

动画演示 · Schur 补消元：矩阵从大变小

左边是完整的 H 矩阵热图（蓝=相机块 B，绿=点块 C，橙=耦合 E）。点"执行消元"，看绿色点块被消去、橙色耦合消失，只剩紫色的紧凑 Schur 补 S。

当前：完整 H 矩阵  |  未知量 = 相机 + 三维点（很多）

② 流形：为什么不能直接对四元数做加法

单位四元数必须满足约束 ‖q‖ = 1，它活在一个球面（三维球面 S³）上。而优化器默认的参数更新是加法 q ← q + Δ——这一步通常会让 q 离开球面，约束被破坏。

普通更新：q + Δ  →  ‖q+Δ‖ ≠ 1  (跑到球外，不再是合法旋转) 流形更新：沿切平面走 Δ，再 投影/归一化 回球面  →  ‖q‖=1 ✓

Ceres 的 EigenQuaternionManifold() 就是替你做"切空间移动 + 投影回流形"这件事，保证优化过程中参数始终是合法旋转。左图用二维单位圆类比球面，演示两种更新的区别。

动画演示 · 普通更新 vs 流形更新（单位圆类比球面）

圆周代表约束 ‖q‖=1。同样沿切线走一步：橙色点直接加位移，跑出圆外（约束被破坏）；绿色点在流形上沿圆弧移动，始终留在圆上。拖动步长看偏离程度。

一句话记住

BA 用 Schur 补是因为三维点数量巨大但彼此独立，可以先消元；流形是因为旋转/角度这类参数有几何约束，更新必须"贴着约束面走"。这两点正是 Ceres 区别于普通最小二乘库的高级能力。
