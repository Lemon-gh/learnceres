01问题设定

数据由曲线 y = e^(0.3x + 0.1) 加上标准差 σ = 0.2 的高斯噪声生成。我们要拟合模型 y = e^(mx + c)，求 m, c。

残差 ri = yi − exp(m·xi + c)

和 Hello World 的唯一区别：现在有 N 个观测点，每个点贡献一个残差块，但所有残差块共享同一组参数 m, c。

02写代码

curve_fitting.cc · 核心片段
struct ExponentialResidual {
  ExponentialResidual(double x, double y) : x_(x), y_(y) {}
  template <typename T>
  bool operator()(const T* const m, const T* const c, T* residual) const {
    residual[0] = y_ - exp(m[0] * x_ + c[0]);
    return true;
  }
 private:
  const double x_, y_;             // 这个观测点的数据
};

double m = 0.0, c = 0.0;           // 待求参数，初值 0
Problem problem;
for (int i = 0; i < kNumObservations; ++i) {
  CostFunction* f =
      new AutoDiffCostFunction<ExponentialResidual, 1, 1, 1>(
          data[2*i], data[2*i+1]); // 把 x_i, y_i 存进仿函数
  problem.AddResidualBlock(f, nullptr, &m, &c);
}
关键模式

循环里每造一个残差块，就把该点的 xᵢ,yᵢ 通过构造函数塞进去。这是 Ceres 处理批量数据的标准写法。

03结果分析

Initial m: 0 c: 0 Final m: 0.291861 c: 0.131439 // 真值 m=0.3, c=0.1

结果偏离真值是正常的——数据有噪声。有意思的是：在真值 (0.3, 0.1) 处评估目标函数得 1.082425，反而比拟合结果的 1.05675 更差。这正说明拟合找的是“最小二乘意义下最好”，不是“离真值最近”。

04鲁棒拟合：抗离群点

如果数据里混入几个离谱的异常点，普通最小二乘会被严重拉偏。只需把 nullptr 换成鲁棒损失：

一行之差
problem.AddResidualBlock(f, nullptr, &m, &c);            // 普通平方损失
problem.AddResidualBlock(f, new CauchyLoss(0.5), &m, &c); // 鲁棒：0.5 是尺度
直觉

平方损失 r² 随残差二次增长，离群点会产生巨大梯度把解拽跑；Cauchy 在大残差处增长变缓，等于告诉求解器“这点可能是噪声，别太当真”。

05练习任务

改初值

把 m、c 的初值改成 (1.0, 1.0)，看迭代次数和最终结果有没有变化。

加离群点

往数据里塞 3 个 y 值放大 10 倍的点，对比有无 CauchyLoss 时曲线的差别。

换模型

把模型换成直线 y = mx + c，改动残差公式和模板参数，重新拟合。

过关标准

能独立跑通曲线拟合，并说清“为什么每个点一个残差块、为什么共享参数”。做到就进入最后的进阶实战。

06原理深挖：鲁棒损失凭什么抗离群点

MATH + ANIMATION

阶段 4 你给残差套了个 CauchyLoss，拟合就不怕离群点了。为什么？这章从"影响函数"的角度讲透原理。

① 问题出在平方：离群点被惩罚得太狠

普通最小二乘的损失函数 ρ(z) = ½z²（z 是残差）。它对残差求导得到影响函数 ψ(z) = ρ′(z) = z——残差越大，这个点往回拉的力量线性无限增长。一个远离群体的离群点，会凭一己之力把整条拟合线拽歪。

② 鲁棒损失：让影响"封顶"甚至回落

鲁棒损失的核心是改造 ρ，使 ψ(z)=ρ′(z) 对大残差有界：

平方   ρ=½z²  →  ψ(z)=z  (直线，无界) Huber   |z|≤δ: ρ=½z²; |z|>δ: ρ=δ(|z|−½δ)  →  ψ(z)=clip(z, −δ, δ)  (封顶) Cauchy   ρ=½δ²ln(1+(z/δ)²)  →  ψ(z)=z / (1+(z/δ)²)  (先增后回落)

Cauchy 的 ψ 在大 z 时反而趋近 0——等于告诉求解器："这个点差得太离谱了，别听它的"。这就是它抗离群点的本质。

③ 在 Ceres 里怎么用

把损失作为第三个参数传给 AddResidualBlock 即可，Ceres 内部会用 ψ 对残差加权：

problem.AddResidualBlock(cost_function, new ceres::CauchyLoss(1.0), &m, &c);

参数 δ（这里是 1.0）是"多算离群"的尺度，按你的残差量级设定。

δ 的量级要对

CauchyLoss/HuberLoss 的参数 δ 要和你的残差量级匹配。δ 设得远大于残差，几乎等于没加鲁棒损失；设得太小，连正常点都被当成离群点丢掉。先用普通最小二乘跑一遍看看典型残差大小，再定 δ。
