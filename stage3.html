01四步流程

① 写代价函数 → ② 建 Problem 加残差块 → ③ 配 Solver::Options → ④ Solve()

定义代价函数

一个带模板 operator() 的结构体，计算残差。

构建问题

Problem problem; 然后 AddResidualBlock 把代价函数和参数绑一起。

配置求解器

Solver::Options options; 设线性求解器、是否打印过程等。

求解

Solve(options, &problem, &summary); 参数被原地更新。

记住这句话

复杂示例 = 换掉第①步的残差公式 + 在第②步多加几个残差块。骨架永远不变。

02三大对象

CostFunction

代价函数

负责算残差向量和雅可比。最常用的是它的自动微分封装 AutoDiffCostFunction。

Problem

问题容器

装着所有残差块和参数块，是要解的整个优化问题，提供 AddResidualBlock。

Solver

求解器

按 Options 的配置执行优化，把结果和报告写进 Summary。

术语对应

术语是什么代码
ParameterBlock一组一起优化的小标量，可单可多&x / &camera, &point
ResidualBlock一个代价函数 + 它依赖的参数AddResidualBlock(...)
LossFunction给高残差降权，抗离群点CauchyLoss(0.5)

03自动微分：一份代码两种用途

你只写一遍残差公式，Ceres 用两种类型调用它：

T = double → 算残差数值（评估误差）　　T = Jet → 残差 + 导数（指导搜索方向）
同一个函数，两种实例化
struct CostFunctor {
  template <typename T>
  bool operator()(const T* const x, T* residual) const {
    residual[0] = T(10.0) - x[0];   // T(10.0) 让运算全在 T 下进行
    return true;
  }
};
// AutoDiffCostFunction<CostFunctor, 1, 1> 完成封装
为什么强推自动微分

精度高（链式法则精确）、省事（不用推导数）、效率高（模板编译期展开）。官方明确建议优先用它。

04三种求导方式怎么选

方式适用推荐度
AutoDiffCostFunction残差能写成模板仿函数（绝大多数）★★★★★ 首选
NumericDiffCostFunction依赖无法改写的库函数，用有限差分★★ 谨慎：贵且易有数值误差
CostFunction 子类要手推雅可比或闭式解更高效★★★ 特殊场景

高级场景还有 DynamicAutoDiffCostFunction（参数尺寸编译期未知）、CostFunctionToFunctor 等，入门阶段先不用管。

05签名里的数字规则

AutoDiffCostFunction<Functor, r, p1, p2, ...>

  • 第一个数字 r：残差维度（这个函数输出几个残差值）
  • 后面每个 p：一个参数块的维度（顺序对应 operator() 里的参数指针顺序）
例子对照
// 残差 1 维，参数 x 1 维
AutoDiffCostFunction<F1, 1, 1>          → operator()(const T* x, T* r)

// 残差 1 维，两个参数块各 1 维
AutoDiffCostFunction<F2, 1, 1, 1>       → operator()(const T* a, const T* b, T* r)

// 重投影误差：残差 2 维，相机 9 维 + 点 3 维
AutoDiffCostFunction<Reproj, 2, 9, 3>   → operator()(const T* cam, const T* pt, T* r)
易错点

数字个数、顺序必须和 operator() 的形参完全一致，否则编译期或运行期报错。

06原理深挖：自动微分为什么能"免费"算导数

MATH + ANIMATION

你写了 T(10.0) − x[0]，Ceres 就同时拿到了残差值和导数，而你没有手写任何导数公式。这背后的魔法叫对偶数（dual number）/ Jet。这章拆给你看。

① 把"数"扩展成"数 + 导数"的数对

定义一个新类型的数：a + b·ε，其中 a 是普通数值，b 是它的导数，ε 是一个满足 ε² = 0 的符号。你只关心 a 和 b，ε 只是"标记导数位置"的记账符号。

② 四则运算规则（导数由运算自动带出）

(a+bε) + (c+dε) = (a+c) + (b+d)ε (a+bε) · (c+dε) = (ac) + (ad+bc)ε  (因为 ε²=0)

看乘法里的导数部分 ad+bc——正是乘积的求导法则！再看平方：

(x + 1·ε)² = x² + 2x·ε  →  值=x²，导数=2x

③ 链式法则：复合函数逐层传播

把函数拆成基本运算（+ − × ÷ sin exp …）的序列，每个运算都按上面的规则把导数往下传。输出数对的 b 部分，就是整个函数对输入 x 的导数。这就是 Ceres 模板仿函数里 T 用 Jet 实例化时发生的事——你写残差公式的每一步，导数都被同步算出来了。

动画演示 · Jet 数对沿计算链传播

以 f(x)=x²+sin(x) 在 x=1 为例。点"单步"，看数对 (值, 导数) 如何一层层流到输出。每个节点上半部分是值、下半部分是导数——导数从头到尾没用你手写一条公式。

三种求导方式，为什么首推自动微分

自动微分（本页）：精度达到机器精度，代码就是公式，维护最省事。数值微分：用 (f(x+h)−f(x))/h 近似，精度受 h 影响，慢。解析微分：手写雅可比，最快但极易写错、难维护。除非性能瓶颈，否则一律用自动微分。
